An enterprise-grade cybersecurity portfolio showcasing threat defense systems, incident response pipelines, machine learning security models, and interactive live cyber defense simulators.

---

## 🛡️ Key Projects & Research

- **Multi-Layer Security Dashboard (MLSD)**: Real-time risk scoring engine isolating brute-force attacks in decoy honeypots with centralized telemetry logging. Presented at ICSEAIS 2026.
- **AI-Based Network Intrusion Detection System**: Machine-learning driven IDS trained on the NSL-KDD benchmark dataset to detect DoS and probe attacks in sub-15ms packet latency.
- **Phishing Detector & Security Assistant**: AI threat analysis scanning suspicious URLs, domain homoglyphs, and email NLP semantics.
- **Interactive SOC Simulators**: Live interactive demonstrations including Honeypot Sandboxes, IDS Traffic Analyzers, Password Vault Hash Audits, and Vulnerability Scanners.

---

## ⚙️ Telemetry & Defensive Architecture

- **Real-Time SOC Telemetry**: Captures client telemetry, in-app browser identification (WhatsApp, LinkedIn, Telegram), hardware profiles, and ISP routing gateway location, instantly dispatching encrypted alerts to the operator's Telegram bot.
- **Automated Daily Visitor Recap (Vercel Cron)**: Nightly aggregation scheduled at `23:59 IST` (`18:29 UTC`) compiling total views, unique visitors, resume interactions, and top referrers directly to Telegram.
- **Identity Handshake Access Gate**: Interactive cyber terminal modal requiring visitor verification before session initialization.
